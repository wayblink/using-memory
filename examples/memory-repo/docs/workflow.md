# Workflow Topic: Daily Standup Prep

Load this document only when `docs/index.json` matches a task that asks for a standup summary or coordination plan. It is not read by default during every session.

1. Review the last `daily/YYYY-MM-DD.md` for `[decision|...]` entries to remind yourself what changed.
2. Summarize progress, blockers, and next steps.
3. Use the checklist below when prepping a standup note:
   - [ ] Confirm blockers still open
   - [ ] Note any new lessons and tag `[lesson|<date>]`
   - [ ] Add any priority shifts to `MEMORY.md`
